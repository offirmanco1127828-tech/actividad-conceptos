# Actividad de conceptos básicos e instalaciones necesarias

## Objetivo

Reconocer y comprobar el funcionamiento de las herramientas necesarias para el desarrollo de software.

## Herramientas utilizadas

- **Git:** herramienta para el control de versiones del código.
- **Visual Studio Code:** editor de código que permite crear y editar archivos, utilizar extensiones y trabajar con proyectos.

## Actividades realizadas

1. Comprobación de la versión de Git mediante el comando `git --version`.
2. Comprobación de la versión de Visual Studio Code mediante el comando `code --version`.
3. Creación de una carpeta para la actividad.
4. Inicialización de un repositorio Git mediante el comando `git init`.
5. Creación de este archivo README para documentar la actividad.

## Resultado

Se comprobó que Git y Visual Studio Code están instalados y funcionan correctamente en el equipo.
